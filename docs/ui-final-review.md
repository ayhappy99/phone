# 안내 문구와 비교 UX 최종 점검

- 14종 × 5항목에 친근한 짧은 안내와 풀어서 안내를 작성했다(총 140개). 전역 선택 버튼으로 전환한다.
- S26 Ultra의 6.9인치 화면은 큰 화면으로 설명한다. 안내 문구에서 선택하지 않은 제3의 모델로 유도하지 않는다.
- 공식 사양, 전작 대비, 유의사항, 출처와 가격 데이터는 유지했다. 미확인 출시가 8개는 추정하지 않았다.
- 용량별 가격을 같은 용량의 A·B 행으로 정렬했다. 가격 데이터에 없는 용량은 ‘해당 용량 미등록’으로 표시해 미확인 가격과 구분한다.
- 모바일 짧은 안내는 A·B를 나란히 배치한다. 큰 글씨에서는 읽기 쉽도록 한 열로 전환한다.
- 검색 조건을 표시하고 초기화 기능을 추가했다. 제조사 변경 시 시리즈를 초기화하며, 시리즈 선택 시 해당 제조사로 맞춘다.
- Bluetooth 6.0과 6은 차이 필터에서 동등하게 처리한다. 다른 사양의 소수점이나 미확인 값은 임의로 정규화하지 않는다.

## 검증 범위

타입 검사, 데이터 불변 조건과 안내 70쌍 검증, 정적 빌드를 통과했다. jsdom UI 테스트는 서로 다른 모델의 182개 순서 조합에서 두 안내 버전과 용량별 가격 정렬을 검증하고, 검색 조건 초기화·제조사/시리즈 호환·Bluetooth 차이 필터를 확인한다. 배포 워크플로에도 UI 테스트를 추가했다.

모바일 CSS는 소스 수준에서 점검했다. jsdom은 실제 레이아웃을 렌더링하지 않으므로 모바일 실기기·화면 크기별 시각 검증이나 접근성 인증을 대체하지 않는다.
