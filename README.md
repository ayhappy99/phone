# Phone — 휴대폰 판매 상담 비교 도구

Next.js App Router + Tailwind CSS 정적 웹사이트입니다. 별도 서버를 실행하지 않습니다.

## 빌드

```sh
npm ci
npm run typecheck
npm run validate:data
npm run build
```

정적 결과는 `out/`에 생성됩니다. `/phone` 하위 경로에 배포하도록 설정되어 있습니다. main 변경 시 GitHub Actions가 정적 빌드 후 Pages 배포를 시도합니다.

## 현재 구현

- 삼성 7종·Apple 7종, 총 14종. 기존 4종을 유지하고 제조사별 5종을 추가
- 삼성 추가: 갤럭시 S26 FE, Z 폴드8 울트라, Z 폴드8, Z 플립8, A37 5G
- Apple 추가: iPhone 18 Pro, 18 Pro Max, Duo, 17e, Air. Duo는 발표된 출시 예정 모델로 구분
- 브라우저 내 모델 검색, 두 모델 비교, 좌우 교체
- 제조사·시리즈 필터, A 선택 후 B 선택으로 자동 전환, 상단 고정 선택 표시
- 화면·무게·카메라·기본 용량 출시가를 먼저 보여주는 핵심 비교 카드
- 공식 스펙·전작 대비 변화·상담 문구의 3단계 표시
- 용량별 확인된 출고가, 출처 링크, 화면 전체 글자 크기 조절(18·20·22·24px), 고객 질문에 답하는 상담 멘트
- 배터리·USB·Wi-Fi·Bluetooth·SIM·지원 기한 비교, 항목 검색, 다른 값 필터
- 비교 주소 공유 및 인쇄
- 핵심 구현과 phoneData는 `src/app/page.tsx`에 포함

## 데이터 완성도

5개 상담 분류와 10개 공통 비교 항목에 더해 제조사 상세 사양을 모델별로 검색하고 펼쳐 볼 수 있습니다. 한국 공식 문서의 확인 시점 스냅샷이며 분류 수는 모델별로 화면에 표시합니다. 기술 목록을 유지하고 홍보 문장·각주는 사실과 조건 중심으로 정리했습니다. S26 FE는 국내 모델 SM-S741NZKWKOO의 공식 상세 표 16개 분류·66개 항목과 기존 확인된 보충 정보를 수록했습니다(화면 표시 19개 분류·85개 항목). 공식 표에 없는 값은 미기재로 구분합니다. 새 Apple 모델의 개별 각주별 전체 시험 조건은 연결된 원문도 확인해야 합니다. 모든 제조사 문서·변경사항을 망라한다는 의미는 아닙니다. Apple 용량별 출시가 14개 항목은 공식 역사 자료가 부족해 확인 보류입니다. 데이터 확인일과 커밋 날짜는 구분합니다.

기획 원본은 `docs/phone-product-design.md`입니다. 원본의 Vite 제안 이후 사용자 요청에 따라 실제 구현은 Next.js의 정적 export를 채택했습니다.

## 검증 기록

데이터 검사는 14개 고유 모델·제조사별 7종·14열 비교 데이터·출처 참조·출시 예정 및 확인 보류 표시를 검증합니다. 브라우저 검증은 196개 선택 조합, 검색, 모델 교체, 필터, 전체 글자 크기 조절·저장, 비교 주소 공유 및 실패 대체 동작, 상세 사양 검색, 새 모델 비교와 출시 예정 표시, 모바일 페이지 넘침, 상호작용 중 네트워크 요청 여부를 대상으로 합니다. 이 검증은 제품 데이터의 전체 항목 완전성을 보증하지 않습니다.

## GitHub Pages 최초 설정

1. 저장소 Settings → Pages를 엽니다.
2. Build and deployment의 Source를 **GitHub Actions**로 선택합니다.
3. Actions → Deploy phone to GitHub Pages → Run workflow를 실행합니다.

공개 URL: https://ayhappy99.github.io/phone/
