# 데이터 확인 및 미완료 항목

확인일: 2026-09-30 (한국)

## 제조사별 5종 추가와 UI 개선

기존 4종을 보존하고 Samsung의 S26 FE·Z 폴드8 울트라·Z 폴드8·Z 플립8·A37 5G, Apple의 iPhone 18 Pro·18 Pro Max·Duo·17e·Air를 추가했다. 최신 발표·출시 모델 중심으로 선정했으며 Duo는 2026-10-23 출시 예정 상태를 명시했다. 제조사별 총 7종, 전체 14종이다.

추가 모델은 한국 공식 제품 사양·지원 문서·제조사 뉴스룸의 출시 발표를 사용한다. 삼성 폴더블은 16개 분류, A37은 15개 분류, S26 FE는 공식 상세 표 16개 분류·66개 항목과 확인된 보충 정보를 합쳐 19개 분류·85개 항목을 수록한다. 추가 Apple 모델은 40~43개 분류를 수록한다. S26 FE의 국내 SM-S741NZKWKOO(8GB RAM·256GB) 상세 표를 확보하여 네트워크 밴드·센서·USB·SIM·DeX·보안 업데이트 종료일을 반영했다. 다른 지역 모델의 값을 대입하지 않았다. 추가 Apple 사양의 각주별 전체 시험 조건은 원문도 확인해야 한다. 분류·표시 항목 수는 전체 완전성 인증이 아니다.

제조사·시리즈 필터, A 선택 후 B 선택 전환, 고정 선택 표시, 핵심 4항목 비교 카드, 출시 예정 표시를 추가했다. 모든 검색과 비교는 정적 데이터로 브라우저에서 처리한다.

## 추가 반영

배터리 용량/정격값, 동영상 재생/스트리밍, USB, Wi-Fi, Bluetooth, UWB, SIM, 보안 업데이트 종료일, 데스크톱 연결 기능의 10개 비교 항목. 출처는 각 모델별 공식 사양이며 표 아래 연결한다. 서로 다른 제조사의 배터리 시험값에 우열이나 차이율을 부여하지 않는다. 미기재/이번 수집에서 미확인/미지원은 구별한다.

## 출시 가격 검증

기존 확인된 출시가는 보존한다. Apple 구매 페이지 검색 결과에 용량별 판매 가격은 남아 있지만 출시 시점 가격이라는 증거가 충분하지 않아 누락된 출시가를 채우지 않았다. Apple 17 Pro 512GB/1TB와 Pro Max 512GB/1TB/2TB의 출시 당시 한국 공식 가격 자료가 필요하다.

추가 모델의 한국 공식 발표에서 확인한 기본 용량 가격과 삼성의 용량별 출시가만 반영했다. 추가 확인 보류: iPhone 18 Pro 및 18 Pro Max의 512GB/1TB/2TB, 17e의 512GB, Air의 512GB/1TB. 기존 5개와 합쳐 총 14개 가격 항목이다. Duo의 추가 용량 3개는 출시 전 공식 구매 페이지의 발표 가격으로 확인했다. 출시 예정 Duo의 가격은 발표 가격이며 실제 판매 시작을 의미하지 않는다.

## 전체 사양 완료 기준

상세 영역에 삼성 모델당 17개 분류(68/69개 표시 항목), Apple 모델당 37개 분류(329/330개 표시 항목)를 구조화했다. 삼성의 용량별 RAM·여유 공간과 전용색상, Apple의 통신 대역·촬영 모드·포맷·접근성·앱·언어·상품정보·환경 정보를 포함한다. 조건은 삼성 모델당 5개, Apple 모델당 31개로 정리했다. 기술 목록을 유지하고 홍보 문장과 각주를 사실 중심으로 요약했다. 이 수치는 화면의 표시 항목 수이며 원천 전체 완전성 비율 또는 독립 검수 인증이 아니다. 등록 공식 문서의 확인 시점 범위만 다루며 모든 관련 지원 문서나 이후 변경까지 포괄하지 않는다. Apple 제품 페이지의 리디렉션을 발견하여 모델별 공식 지원 문서로 링크를 정정했다.

## 배포와 데이터 검증 구분

타입 검사, 정적 빌드, UI 검증 성공은 제품 데이터의 전체 항목 검증 완료를 뜻하지 않는다. 배포 여부와 데이터 완성도는 독립적으로 표시한다.

## 인바운드 상담 UI 반영 (2026-09-30)

고객의 희망 기종·예산·현재 불편한 점을 먼저 확인하도록 상담 안내를 변경했다. 멘트 복사 버튼과 클립보드 코드·직접 복사 영역을 제거하고, 상담 멘트는 화면에서 읽는 형식으로 유지한다. 기본 글자는 18px이며 20·22·24px로 조절하면 검색·버튼·가격·스펙·각주의 rem 글자 크기가 함께 커진다. 저장이 가능한 브라우저에서는 선택한 크기를 다음 방문에도 유지한다. 제조사 필터·검색을 기본으로 제공하고 시리즈 필터는 펼쳐서 사용한다.

이번 확인에서 추가 10종의 제조사 한국 공식 사양/발표 문서가 제공되는 것을 확인하고 주요 수치와 대조했다. S26 울트라 상담 요약의 퀄컴 자료 기반 공정 수치는 삼성 공식 제품 사양 범위에 맞추어 제거했다. 데이터의 전체 완전성을 인증한 것은 아니며 S26 FE의 확보한 국내 상세 표를 반영했고, 출시 당시 근거를 확보하지 못한 14개 출시가는 확인 보류로 유지한다.
